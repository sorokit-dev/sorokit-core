# Security Policy

## Supported versions

sorokit-core is pre-1.0. Security fixes are applied to the latest release and to `main`.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Use GitHub's private reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**. Include:

- a description of the issue and its impact
- steps or a minimal proof of concept to reproduce it
- affected versions, if known

We aim to acknowledge reports within 5 business days and will keep you updated while we investigate and fix the issue. Please give us a reasonable window to release a fix before any public disclosure.

## Scope

Issues we are particularly interested in include wallet connection and transaction signing flows, transaction construction, and vulnerable or malicious dependencies. Problems in third-party wallets or in the Stellar network itself should be reported to those projects.
